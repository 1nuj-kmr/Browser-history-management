# Browser History Simulator (DLL)

## Description
This project simulates browser navigation using Doubly Linked List in C++.

## Features
- Visit new page
- Back and Forward navigation
- See Full history
- Save history to file
- Load history from file

## Concepts Used
- Doubly Linked List
- File Handling
- Pointers and Memory Management

## How to Run
g++ main.cpp
./a.out
